门店陈列管理优化方案

职责清晰 · 分类管理 · 缺货智能替换 · 陈列如实反映销售

一、为什么要做这件事

当前门店货架陈列变化频繁，系统里的陈列图与货架上的实际情况长期对不上，陈列已经不能真实反映商品的销售情况。

集团要求门店按统一陈列图陈列并上报，但遇到商品缺货时，门店不能让货架空着、必须卖货，只能自行找商品顶上——替换了什么、放在哪、什么时候换的，都没有记录。于是形成了两头为难的现状：

矛盾点：集团要"按统一陈列图陈列上报"，门店要"缺货了也不能不上架卖货"。门店随手替换，既破坏了统一陈列图的严肃性，又让集团看不到货架的真实情况。

问题的根源不在门店，而在三件事没做到位：

  • 职责不清——哪些陈列谁说了算，三个部门之间没有明确边界；
  • 缺货时没有统一规则——换什么商品全凭门店自己判断，换得对不对无从衡量；
  • 替换动作不留痕——换了没有登记、没人知道，陈列图与实际越走越远。

本方案的目标：让陈列始终反映商品实际情况，让"统一管控"和"灵活卖货"不再矛盾。

二、职责清晰化：三个部门各管什么

部门负责的陈列事项要达到的目标
采购部新店开业陈列策划；门店年度性、大幅度的陈列调整统一规划，从源头把陈列设计规范做好
营运部常态化陈列、背柜的日常管理按集团统一陈列图执行，管控住主销商品
门店HPP 位、动销快的位置的陈列调整快速响应销售变化，调整后及时拍照上传陈列图
一句话分工：采购管"从无到有"（新店、大改），营运管"日常不变"，门店管"快变的位置"。各管一段，互不越位，矛盾自然消解。

三、四类陈列，分类管理

把全部门店的所有陈列位归成四类，每一类有明确的责任方、管理方式和要求：

类型陈列范围责任方管理方式关键要求
第一类 动销频繁的位置、地堆位 门店 门店自主调整，及时拍照上传陈列图 快——跟着销售走，但必须有图可查
第二类 品牌类陈列位、热销位 系统
（拱北、横琴、大桥三家大门店先行）		 系统智能替换，不需要审核 快速响应，陈列自动更新
第三类 常态化陈列位、背柜 营运部 按集团统一陈列图管理 稳——保证集团主销商品的管控
第四类 新店陈列策划、时间跨度大的门店大调整 采购部 采购统一规划陈列 规范——从源头保证设计质量

四类陈列覆盖了门店所有场景：卖得快的门店说了算（但要拍照上报），品牌和热销的系统自动管，常态的集团统一管，开新店采购统一规划。陈列管理的每一种情况都有明确的章法。

四、智能替换规则（针对第二类陈列）

智能替换只在品牌类陈列位和热销位上启用，先在拱北、横琴、大桥三家大门店落地。核心思路：建陈列的时候就给每个陈列柜贴上属性标签，缺货时按属性找"最像的商品"顶上。

第一步：给陈列柜定属性

新建陈列时，每个陈列柜按柜内商品的共同特征标识为三种属性柜：

陈列柜属性判定特征替换时优先遵循的原则
品牌陈列柜柜内商品为同一品牌品牌优先——先找同品牌商品
高价值陈列柜柜内商品价格带相近（±20%以内）价格带优先——先找同价位商品
快销陈列柜柜内商品销量带相近（±20%以内）销量优先——先找卖得一样快的商品

柜组属性由五个维度共同定义：同品类同品牌同价格带（20%以内）同销量带（20%以内）同供应商

第二步：按"属性优先、顺序递补"找替代品

不做复杂打分，采用简单明确的优先顺序原则：先找与陈列柜属性一致的商品；找不到，就按固定顺序逐项递补，直到找到第一个满足条件的商品。

陈列柜属性替换顺序（从先到后）
品牌陈列柜同品牌 → 同品类 → 同价格带 → 同销量带 → 同供应商
高价值陈列柜同价格带 → 同品牌 → 同品类 → 同销量带 → 同供应商
快销陈列柜同销量带 → 同品牌 → 同品类 → 同价格带 → 同供应商
替代品怎么圈出来：把商品按销量排序，断货商品在排序中的上一个或下一个商品，就是"卖得和它差不多快"的自然候选——再按上面的顺序核对属性即可。规则简单、门店好理解、系统好实现。

五、替换怎么通知、怎么执行

整个流程免审核、全程留痕，门店一个动作完成，管理层只需知会：

库存为 0门店监管仓或大仓库存归零
→
PAD 消息系统自动推送提醒到门店 PAD
→
一键替换门店按系统给出的替代商品一键上架
→
OA 通知替换结果自动推送采购部、营运部
→
查看即可不做审核；有问题线下沟通调整
  • 推送时机：门店监管仓或大仓库存为 0 时，系统自动推送 PAD 消息提醒门店；
  • 执行方式：门店在 PAD 上一键替换，系统按第四节规则给出替代商品；
  • 知会机制：替换完成后通过 OA 消息推送采购部和营运部，查看即可、不做审核，保证响应速度；
  • 纠偏渠道：如果替换不合适，营运部线下与门店沟通调整陈列，不在线上设卡。

六、这套方案带来什么

解决的现状问题方案带来的改变
陈列与实际对不上，看不出商品销售情况缺货替换有规则、有记录，换的是什么、什么时候换的一清二楚，陈列始终反映真实销售
集团统一陈列图与门店卖货需求冲突四类陈列各有章法：该统一的统一管，该灵活的放开管，矛盾不再出现
三个部门职责交叉、说不清谁的责任采购管源头、营运管常态、门店管快变，职责边界清晰
大门店热销位缺货后长时间空置库存归零自动提醒、一键替换、免审核，当天完成补位，不空货架、不丢单
实施范围说明：智能替换先在拱北、横琴、大桥三家大门店的品牌位与热销位落地，跑顺后视情况推广；第一、三、四类陈列管理方式即日可按职责执行。
