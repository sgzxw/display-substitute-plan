陈列断货智能替代落地实施方案

目标：断货商品所在陈列位，系统自动推荐可替换商品，门店照单执行；替代全程可追溯，原品到货自动恢复。本文只讲模型思路与落地路径，取数/SQL 不在本文范围。

一、问题与目标

现状痛点：

  1. 陈列商品断货 → 货架空置，销售机会流失（放满陈列可提升约 24% 销售）
  2. 人工随便拿货补位 → 补了什么没人知道、系统不记录
  3. 补的商品与陈列模板设计意图不符 → 破坏价格带梯度、品类逻辑、视觉陈列

目标一句话：让"断货 → 补位 → 追溯 → 恢复"这条链路自动化、可配置、可度量。

二、模型总思路（四句话）

  • 用消费者决策树（CDT）定义"像不像"：替代品必须与原商品在同一条决策分支上（同小类 → 用途/口味 → 价格带），顾客拿不准时才会因"看起来差不多"而成交。
  • 用共购行为定义"相近"："口味/用途相近"不靠人工判断，靠小票共购——买 A 的人还买了同小类、同价格带、同用途的 B，A 和 B 就互替。不限品类、不限品牌。
  • 用配置表承载规则：所有阈值和权重策略化，运营改配置即改策略，不碰代码。
  • 用登记闭环保证可追溯：每次替代落系统，每日快照 diff 兜底识别，原品到货自动触发恢复。
断货判定 → 候选池（硬过滤）→ CDT 打分 → 三路径执行 → 登记闭环
原品到货，自动恢复原陈列 ◄──────────────────────┘

三、模型怎么"想"——单个断货位的决策推演

以一个真实场景走一遍（商品名为示意）。

第 0 步 · 发现断货

快照比对：陈列位（店 20208 / 货架 1 / 1 层 3 列）昨日摆的是"海蓝之谜紧致焕颜精华晚霜"，今日库存检查发现店面仓 0、监管仓 0 → 判定"断货"（临断且在途 1 天内到货 → 直接挂缺货牌，到此结束）。

第 1 步 · 圈定候选池（硬条件，缺一不可）

同店在售、同小类（面霜）、非赠品非滞销、可用库存够摆满这个位的陈列面。先做硬过滤，把几千个 SKU 缩到几十个。

第 2 步 · 按 CDT 打分（谁最像它）

表 1　CDT 打分维度与示例判定（合计满分 100 分）
维度分值示例判定
行为互替35查互替分中间表——买海蓝之谜面霜的人，小票里还买了谁？若"莱珀妮面霜"共购 lift=2.8 且价格差 15% → 满分
用途相同15同细类"修护面霜" → 满分
价格带20候选价差 ±20% 内 → 满分（顾客预算校验是最后一关）
规格相似15同为 30ml 级 → 满分
动销热度10该品近 30 天同店销量分位 85% → 高分
品牌加成5跨品牌 → 0 分（品牌不是前提，只加成）

示例候选合计约 95 分。

第 3 步 · 三路径分流

  • 得分 ≥ 70 → 同类替代：推荐单给出 Top3，店员选一个上架
  • 40–70 → 空间延展：不换品，让旁边畅销品扩排面填满
  • 得分低于 40 或无候选 → 缺货标识：挂"此货暂缺"，绝不硬补

第 4 步 · 登记与恢复

替代动作落登记表（原商品/替代商品/位置/时间/得分/预计恢复日）；海蓝之谜到货当日 → 系统自动生成"恢复原陈列"任务，替代品退位，闭环。

模型的全部智慧集中在第 1、2 步的规则上；第 3、4 步是执行纪律。

八、效果度量（模型好不好，看这四个数）

  1. 断货位空置时长：从断货判定到补位完成的平均小时数（核心效率指标）
  2. 替代成交率：替代品在位期间日均销量 / 原品近 90 天日均销量（衡量"像不像"——CDT 打分准不准的直接证据）
  3. 模板一致率：货架上非模板商品的占比下降幅度（替代登记 + 快照 diff 双口径）
  4. 恢复及时率：原品到货后 24h 内恢复原陈列的比例（闭环健康度）

灰度期用对照门店做差分，全量后按月追踪趋势并反哺权重配置。

九、实施边界与原则

  • 先纪律后智能：阶段 1 的价值一半来自"禁止乱放 + 强制登记"，规则本身不用很聪明
  • 推荐不夺权：系统只推荐 Top3，最终由店长确认；"替代转正式"必须商品部审批
  • 价格带是红线：超 ±40% 一票否决，宁可空位挂缺货牌，不让顾客觉得"货不对板"
  • 监管合规硬约束不可配置：监管合规类规则不进策略表，写死在引擎里
